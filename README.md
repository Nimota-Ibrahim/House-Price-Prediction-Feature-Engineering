# House-Price-Prediction-Feature-Engineering

### Follow-Up Study of a House Price Intelligence Pipeline

This project is a follow-up to an earlier house price prediction model, building directly on the baseline **XGBoost pipeline**. [Link to baseline project here](https://github.com/Nimota-Ibrahim/House-Price-Intelligence-Pipeline/blob/main/README.md
)

The objective of this extension is not to replace the original model, but to explore how additional aggregated and transformed features influence prediction logic, error patterns, and model stability. By examining these changes, the study highlights trade-offs between model stability, interpretability, and predictive accuracy, providing deeper insight into the real-world impact of feature engineering on machine learning models.
